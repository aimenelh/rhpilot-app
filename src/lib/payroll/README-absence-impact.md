# Impact paie des absences

Une absence validée est une donnée RH source. Son effet sur le bulletin est calculé uniquement à partir d'une règle de paie versionnée et applicable à la période.

Le moteur distingue le chevauchement calendaire, puis la base de valorisation réellement définie par la règle. Il ne déduit jamais automatiquement un mode de calcul à partir du type d'absence.
